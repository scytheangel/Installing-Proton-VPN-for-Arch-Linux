# Installing-Proton-VPN-for-Arch-Linux
I'll be walking you through the steps on installing proton VPN on your Arch or any Arch-based Linux distros.

<img width="1283" height="995" alt="image" src="https://github.com/user-attachments/assets/c153efaf-57b6-4cc0-99f9-ff9cf619525e" />

Go to protonvpn.com/download 

<img width="1283" height="995" alt="image" src="https://github.com/user-attachments/assets/07f096de-6b4b-484c-8ee7-f3b4d8e11b5d" />

Tap on the button saying "Download for Linux" and scroll down and select Arch

<img width="1283" height="995" alt="image" src="https://github.com/user-attachments/assets/6cdc0bcf-dc42-456e-865d-daf43ad147c5" />

Copy any of the given commands, preferably the first, add "sudo" followed by pasteing the command command you just copied.

The terminal will ask if you want to proceed with installation, press y to continue

<img width="1068" height="742" alt="image" src="https://github.com/user-attachments/assets/4f86e74f-a5c7-4478-997e-7e1a4c39db8a" />

ProtonVPN should now be installed on your linux device.
